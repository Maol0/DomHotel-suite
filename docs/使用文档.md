# DomHotel 智能酒店套件 — 使用文档

> 版本：v1.4.1  
> 更新日期：2026-09-11  
> 适用场景：中大型酒店 / 公寓 / 度假村客房服务数字化

---

## 一、产品概述

DomHotel 智能酒店套件是一套基于企业微信 + 微信客服的酒店客房服务管理系统，实现住客需求自动受理、AI 智能应答、工单流转、员工移动端接单的全流程闭环。

### 核心能力

| 角色 | 能力 |
|------|------|
| **住客** | 微信客服提需求、H5 扫码下单、查看进度、确认完成、评价 |
| **员工** | 企微 OAuth 免登、移动端接单/完成、AI 建议话术 |
| **管理** | 后台看板、知识库管理、会话质检、全链路冒烟检测 |

## 二、住客使用指南

### 2.1 微信客服提需求

住客关注酒店微信客服号后，可直接发消息提需求：

| 指令 | 示例 | 说明 |
|------|------|------|
| 自然语言 | `1209要两双拖鞋` | 自动识别房间号+需求类型+物品 |
| 报修 | `报修 空调不制冷` | 快速创建维修工单 |
| 绑定 | `绑定 1206 张三` | 绑定房间后享受个性化服务 |
| 状态 | `状态` | 查询当前房间状态和进行中工单 |
| 解绑 | `解绑` | 解除房间绑定 |

**AI 智能应答**：非指令消息由 AI 智能体自动回复，支持酒店设施、政策、周边信息问答（基于知识库）。

### 2.2 H5 扫码下单

扫描房间内二维码进入下单页：

```
https://guishan.paw.domai.fun/api/domhotel-suite/ui/guest-h5.html?room=1206
```

- 房号自动填入（URL 参数预填）
- 选择需求类型：送餐、送物、清洁、维修、其他
- 填写描述和紧急度
- 提交后收到确认

### 2.3 查看我的需求单

扫码或点击提交成功页的链接：

```
https://guishan.paw.domai.fun/api/domhotel-suite/ui/guest-orders.html?room=1206
```

功能：
- 查看所有需求单及状态
- 处理中/待处理的工单可点击「确认完成」
- 已完成的工单可评分（1-5 星）和写评价

### 2.4 二维码管理

管理后台生成和下载二维码：

```
https://guishan.paw.domai.fun/api/domhotel-suite/ui/guest-qr-admin.html
```

- 通用二维码：所有房间共用
- 一房一码：每个房间专属二维码（推荐）

## 三、员工使用指南

### 3.1 企微 OAuth 免登

在企业微信中点击应用菜单或扫描工作台二维码，自动登录：

1. 企微里打开「酒店房务工作台」应用
2. 自动跳转企微授权页
3. 授权后自动登录，无需输入密码

**前提条件**：
- 员工表中已绑定 `wecom_userid`
- 企微后台已配置网页授权域名：`guishan.paw.domai.fun`

### 3.2 接单与完成

| 操作 | 说明 |
|------|------|
| **接单** | 工单状态从「待处理」变为「处理中」，客人收到通知 |
| **完成** | 工单状态变为「已完成」，客人收到完成通知，可联动房态 |
| **转单** | 退回工单池，等待重新分配 |
| **暂停** | 暂停处理，需说明原因 |

### 3.3 AI 建议话术

每个工单卡片上有「🤖 AI话术」按钮：
- 点击后 AI 根据工单信息生成回复客人的话术
- 一键复制后发送给客人
- 可重新生成

### 3.4 员工工作台地址

```
https://guishan.paw.domai.fun/api/domhotel-suite/ui/staff-h5.html
```

## 四、管理后台

### 4.1 主要功能

| 功能 | 说明 |
|------|------|
| **房态看板** | 楼栋→楼层→房型→房号四层展示 |
| **工单看板** | 按状态分栏：待处理/处理中/已完成 |
| **前台接待** | 客人入住登记、退房、CSV 导出 |
| **报表统计** | 房态分布、在住客人、交接班记录 |
| **后台配置** | 企微设置、权限管理、部门管理 |
| **知识库** | 编辑 AI 客服参考的酒店 FAQ |
| **会话质检** | 查看微信客服会话历史（AI/人工/接管） |
| **冒烟检测** | 全链路健康检查 |

### 4.2 知识库管理

```
https://guishan.paw.domai.fun/api/domhotel-suite/ui/kb-admin.html
```

使用 Markdown 格式编辑，建议按 `##` 标题分段。保存后 AI 客服立即生效。

### 4.3 会话质检

```
https://guishan.paw.domai.fun/api/domhotel-suite/ui/kf-sessions-admin.html
```

查看微信客服会话流，区分：
- 🟢 客人消息
- 🔵 AI 回复
- 🟠 人工客服回复
- 🔴 接管事件

### 4.4 冒烟检测

```
GET /api/domhotel-suite/admin/smoke-test
```

检查项：
- 数据目录可写
- 敏感凭证文件权限
- 企微 API 链路
- 微信客服配置
- 回调 URL 可达性
- AI 智能体配置

## 五、配置说明

### 5.1 企微配置

| 配置项 | 来源 | 说明 |
|--------|------|------|
| WECOM_CORP_ID | 运行时配置 | 企业 ID |
| WECOM_AGENT_SECRET | .wecom_secrets | 自建应用 Secret |
| WECOM_AGENT_ID | 运行时配置 | 自建应用 AgentId |
| WECOM_KF_ID | 运行时配置 | 微信客服账号 ID |
| WECOM_KF_TOKEN | .wecom_secrets | 回调 Token |
| WECOM_KF_ENCODING_AES_KEY | .wecom_secrets | 回调 AESKey |
| KF_CALLBACK_BASE_URL | 运行时配置 | 公网回调地址 |
| KF_NOTIFY_USERIDS | 运行时配置 | 通知员工列表 |

### 5.2 安全说明

- 敏感凭证存储在 `.wecom_secrets` 文件（权限 0600）
- 运行时配置 JSON 不含 Secret 字段
- API 不回显 Secret 值
- XML 解析拒绝 DTD/实体声明（防 XXE）

## 七、常见问题

**Q: 员工打开工作台要输密码？**  
A: 需要在企微后台配置「网页授权登录的可信域名」为 `guishan.paw.domai.fun`。

**Q: 微信客服不回复？**  
A: 检查冒烟检测（`/admin/smoke-test`），确认回调 URL 和可信 IP 配置正确。

**Q: 客人下单没通知？**  
A: 检查 `KF_NOTIFY_USERIDS` 是否配置了员工 userid。

**Q: 模板卡片发不出去？**  
A: 检查 `WECOM_AGENT_ID` 是否配置，员工是否有 `wecom_userid`。
