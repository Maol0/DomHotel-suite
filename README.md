# Agent Office · 智能体办公室

一个 QwenPaw **插件**（前端看板 + 轻量后端），用拟物"办公室"的方式实时展示每个
智能体的工作状态：谁在忙、忙了多久、刚完成了什么，以及智能体之间的派活协作。
头像存在后端，**团队统一、跟人走**。

适合的场景：你的主智能体把任务派给其他智能体后，想一眼看清"它们到底有没有在干活、进展如何"。

## 功能

- **办公室看板**：每个智能体一个工位，扁平插画风格。
  - 🟢 忙碌（有任务在跑）：小人有打字/呼吸动效、桌灯亮起、显示"已忙 X 分钟"。
  - ⚪ 空闲：显示"Y 前完成"。
  - ⚫ 禁用：工位灰显。
  - 右上角角标显示同时运行的任务数。
- **派活飞行轨迹**：当检测到"A 智能体派活给 B 智能体"的协作会话时，会在两张
  工位卡片之间画出一条连线，信使光点沿线飞行、箭头指向干活的一方，并带「A → B」
  小标签；同时 B 的工位仍会显示"来自 A"标签，谁派给谁一目了然。
- **主管工位**：名册中的第一个智能体标记为 👑 主管位。
- **点击工位**：抽屉展开该智能体最近的任务/对话列表，再点进去可查看具体消息内容。
- **顶部概览**：忙碌 / 空闲 / 禁用数量统计，刷新频率切换（1s / 3s / 10s），手动刷新。
- 标签页隐藏时自动降频轮询，节省资源。

## 数据来源

插件不修改 QwenPaw 核心，仅通过现有 REST API 读取数据：

| 用途         | 接口                                      |
| ------------ | ----------------------------------------- |
| 智能体名册   | `GET /api/agents`                         |
| 实时运行状态 | `GET /api/agents/{id}/agent-status`       |
| 任务/对话列表 | `GET /api/agents/{id}/chats`             |
| 对话详情     | `GET /api/agents/{id}/chats/{chatId}`     |

> 说明：`agent-status` 反映的是该智能体整体"在忙/在闲"及运行中的任务数，
> 不包含单条任务的百分比进度（核心未提供该数据）。本插件用"运行时长 +
> 最近任务"来近似表达进度。

插件自带的头像接口（由本插件后端提供，挂在 `/api/agent-office` 下）：

| 用途           | 接口                                       |
| -------------- | ------------------------------------------ |
| 读取全部头像   | `GET /api/agent-office/avatars`            |
| 设置某个头像   | `PUT /api/agent-office/avatars/{id}`       |
| 删除某个头像   | `DELETE /api/agent-office/avatars/{id}`    |

头像以 `data:` URL 内联返回，避免 `<img>` 无法携带鉴权头的问题；文件存放在
`WORKING_DIR/agent_office/avatars/<智能体ID>.<ext>`。

## 构建与安装

```bash
cd plugins/bundle/agent-office/frontend
npm install
npm run build           # 产出 frontend/dist/index.js

# 安装插件（QwenPaw 需离线）
qwenpaw plugin install plugins/bundle/agent-office

# 启动后，侧边栏会出现「智能体办公室」🏢
qwenpaw app
```

## 头像

头像按以下优先级解析：**服务端头像（团队共享）> 按智能体 ID 内置的图 > 首字母色块兜底**。

### 1. 在界面里设置（推荐，存后端、团队共享）

点击任意工位 → 抽屉里有「头像」编辑区：

- **上传头像**：选本地图片，前端自动中心裁剪并压缩到 256×256，然后 `PUT` 到后端
  保存，**立即生效、换浏览器/换机器都保留、跟着智能体走**。
- **预设头像**：内置 5 个雪豹角色（主管 / 代码 / 研究 / 写作 / 运维），点一下即上传应用。
- **恢复默认**：从后端删除该智能体的头像，回到内置图或色块。

> 说明：头像存放在 QwenPaw 工作目录（`WORKING_DIR/agent_office/avatars/`），
> 由插件后端统一存取，所以是"团队统一、跟人走"的，而不是只存在本机浏览器。

### 2. 打包内置头像（可选，作为默认底图）

把 `<智能体ID>.png`（建议 1024×1024、透明、头肩居中）放进
`frontend/src/assets/agents/`，重新 `npm run build` 即作为该智能体默认头像
（用户仍可在界面覆盖）。命名规则见 `frontend/src/assets/agents/README.md`。

### 预设头像

预设图位于 `frontend/src/assets/presets/`（`supervisor/code/research/writing/ops.png`），
扁平插画、透明背景。要增删预设，改这个目录后重新 build 即可。

## 办公室背景

`frontend/src/assets/office-bg.{png,jpg}`（建议 16:9）会作为 Hero 横幅插画；
缺省时用柔和渐变兜底。

> 所有打包图片会在构建时内联进单一 `index.js`，无需额外静态资源服务。
